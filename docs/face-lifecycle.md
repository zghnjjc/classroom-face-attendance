# 人脸授权、期限与受控清理

本页说明软件行为，不构成法律意见，也不替学校决定告知内容、同意要求或保存期限。软件记录教师核验过的授权，不在线收集签名、不核验监护人身份、不认定法律效力。需要保留真实凭据并由学校自行核定流程。

## 1. 升级与首次启用

本轮数据库升级为 **schema 5**。升级前完整备份，关闭所有旧版窗口；升级后只使用新程序访问该数据目录。需要回退时，使用升级前备份，不让旧程序读取新库。

旧学生、名单、考勤、首次人脸到课时间证据、密码、模板和核对记录保留。**不为旧样本自动补授权**。未登记、已撤回、已到期、告知已更新或恢复后待复核的资料，均不能直接用于采集、训练或刷脸。可继续人工点名、查询与导出。

## 2. 发布学校核定的告知

教师登录，进入“人脸授权”，点击“发布新告知”：

1. 填写唯一版本号与完整正文。正文应由学校核定，说明用途、资料范围、保存期限原则、访问者、撤回渠道及人工点名替代方式。
2. 明确勾选核定确认后发布。软件不预置可直接当作正式文件使用的告知模板。
3. 每版正文、SHA-256 与发布时间保存在数据库；不能通过业务接口覆盖或删除历史版本。
4. 新版本发布后，旧版本授权转为受限，需逐人查看新告知并重新登记，不推定同意新条款。正式发布会影响现有刷脸，请选择适当时间。

“查看当前告知”可查看正文及校验值。校验值用于发现内容变化，不证明学校身份、签署人身份或法律效力。

## 3. 登记 / 续期授权

选择学生，点击“登记 / 续期授权”：

- 查看当前完整告知，核验本人或监护人的真实明确同意；未同意者使用人工点名。
- 选择同意方式，登记凭据引用。建议仅填内部编号或受保护的凭据位置，不把身份证件、扫描件或签名图片放入程序。
- 显式填写保存截止日，**不预填期限**。截止日当天有效，次日本地时间零点起失效；日期不能早于登记当天。
- 勾选已展示此版告知、已核验同意与期限，再确认登记。告知或授权在填写期间变化，会拒绝旧预览，要求重新查看。
- 续期产生新记录，不覆盖旧记录。名单导入、启用学生、首次向导、摄像头检测和模型训练都不代替授权登记。

期限判断依赖本机日期时间；部署时应确保系统时钟与时区正确。教师首页和授权页每约 30 秒刷新授权概要，保存截止前 14 天内显示到期提醒；这是程序运行期间提醒，不是后台常驻通知。

## 4. 撤回与使用门禁

“登记撤回”需填写原因或请求凭据引用。提交后记录撤回，不删除历史授权。采集每次保存前、训练选取与发布前、识别运行时及签到写事务均检查授权状态；签到同时检查业务到课时间和当前时间，不能靠回填旧时间绕过到期。

合并模型若含任何没有当前有效授权的身份，会整体暂停用于签到，避免仅过滤最终标签却继续使用其模板。识别运行时约每 0.75 秒重查模型与授权，最终签到事务再次校验。可清理并重新训练仅含有效授权者的模型，或暂时人工点名。

撤回不等于文件已删除。已保存样本、模型及备份副本需分别处理。停用学生也不等于撤回授权；普通“删除人脸”不等于删除授权历史。

## 5. 受控清理

停止所有采集、识别、训练和备份，点击“预览受控清理”：

1. 预览将移除的受限或无法归属的样本，及需要移除的合并模型/清单。有效授权者的原始样本保留；合并模型包含他人模板时可整体移除，之后另行训练。
2. 复核管理密码、填写清理原因，并再次确认。授权、文件内容或日期状态发生变化，会拒绝旧预览，保护后来已重新授权或变化的文件。
3. 确认清理意图先写入数据库，再在资源锁内逐文件核对哈希、暂存并删除。每个暂存文件有界命名，支持旧长文件名。
4. 最后写入完成记录。中断、取消、占用或失败时，不宣称完成；保留可续办任务，期间所有人脸使用、登记新授权和新完整备份暂停，人工点名仍可用。
5. 重新登录后，在“人脸授权”点击“续办未完成清理”，复核密码继续。已删除部分不重复删除；内容变化、链接、未知文件或无效清单停止处理，需人工核对，不自动强删。

清理不删除名单、课次、考勤、首次到课时间证据或授权/撤回历史，也不追溯删除历史备份、导出、恢复前快照或手工副本。普通文件删除不承诺不可恢复擦除。已确认任务不提供界面撤销；异常时请保留现场数据并核对，不要手工删除任务记录来绕过暂停。

## 6. 备份与恢复

- 支持只读校验及恢复 schema 3、4、5；旧库在首次打开时事务升级，不在校验阶段迁移。
- 新备份包含告知、授权/撤回历史、期限和清理完成记录；有未完成清理时拒绝生成新完整备份。
- **所有恢复后的授权默认待复核**。即使备份内的同意当时有效，也不能直接恢复刷脸；旧备份可能早于撤回请求，不能据此“复活”同意。
- 授权页逐人查看当前告知、核验真实凭据并重新登记后，才恢复该生资格。模型含其他待复核者时仍暂停；需复核全部相关身份，或清理后训练授权子集。
- 备份校验中的模型可用状态表示备份当时内容及当前可校验状态，不代表恢复后直接获得人脸使用资格。授权不影响恢复后的人工点名和历史查询。
- 恢复前快照与所有旧 ZIP 仍可能含已撤回或到期资料，需由部署方另外按策略保护和清理。

## 7. 边界与未完工作

- 这是本地工程控制，不是生物识别使用的合法性认证；共享管理密码也不提供独立教师身份。
- 授权凭据引用、历史版本及操作记录也是受保护的本地资料，不自动按人脸期限删除。
- 未提供云端同意收集、凭据原件托管、跨机器撤回同步、历史备份自动追溯清除或不可恢复擦除。
- 真机连续签到、拔插、干净电脑离线运行、换机恢复与课堂准确率/耗时评测仍需现场验收。

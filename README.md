# 课堂签到 · Classroom Face Attendance

一个用 Python 和 OpenCV 编写的 Windows 课堂考勤桌面项目，支持**人脸签到、人工点名、课次管理和 Excel 报表**。程序在本机离线运行，数据保存在本地。

> **当前状态：开发与验证阶段，适合学习、演示和功能体验，暂不建议直接用于正式课堂考勤。**
>
> 仓库提供源码和构建脚本，不附带真实学生名单、人脸样本、训练好的识别模型或考勤数据库。首次运行需自行设置，可以先用虚构资料体验人工点名。
>
> 识别效果和长期稳定性尚未经过充分的真实课堂验证；已有功能和自动化测试不代表已经达到实际部署条件。

## 可以体验什么

- **名单与排课**：添加或导入学生，创建单次课次，也可按每周安排批量生成课次。
- **两种签到方式**：学生逐人刷脸签到，或由老师人工点名；人工点名不需要摄像头和人脸模型。
- **核对与报表**：查看今日课堂、核对和更正考勤，按学生或课程汇总并导出 Excel。
- **资料管理**：登记人脸授权与保存期限，清理人脸资料，备份和恢复数据；可设置教师端运行期间的每日自动备份。

技术栈：Python 3.11 · OpenCV · Tkinter · SQLite。不了解这些技术也可以按下面的步骤尝试运行。

## 怎么运行

准备一台 **Windows 10 / 11** 电脑，安装 **Python 3.11**。安装依赖需要联网；体验人工点名无需摄像头，体验刷脸才需要。

**1. 下载源码**

在本仓库页面点击 **Code → Download ZIP**，解压。打开能看到 `app_entry.py` 和 `requirements.txt` 的文件夹，在这里打开 PowerShell（终端）。

**2. 安装依赖并启动**

依次执行下面三行命令；上一行成功后再执行下一行：

```powershell
py -3.11 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe app_entry.py
```

如果提示找不到 `py`，先用 `python --version` 确认是 Python 3.11，再把第一行的 `py -3.11` 换成 `python`。以后启动只需执行最后一行。

**3. 先用测试资料熟悉界面**

首次启动会引导你选择数据位置、设置管理密码、测试摄像头和准备名单；项目没有默认密码。可以选择“跳过摄像头，使用人工点名”，先添加几位虚构学生，创建当前时段的课次，再从“人工点名”体验登记、核对和导出。

要体验刷脸，请使用本人或明确同意参与测试者的资料：**登记人脸授权 → 采集样本 → 更新识别模型 → 创建并开启课次 → 进入“学生签到”**。没有有效授权、样本和模型时，无法直接刷脸签到。

目前以源码方式体验，尚未发布可直接下载的 EXE 发行包。桌面快捷方式和自行打包的方法见 [启动与构建说明](docs/deployment.md)。

## 使用前需要知道

- **没有可靠的活体检测**：不能承诺识别照片、视频代刷，识别结果需要人工核对。
- **可能认错或认不出**：光线、角度、遮挡和摄像头都会影响效果，目前没有可用于真实课堂承诺的准确率数据。
- **面向单机使用**：同一时刻一个签到课次，不支持多教室联网管理；Linux、macOS 和其他 Python 版本未验证。
- **请保护测试资料**：不要把真实人脸、名单、数据库、模型或备份上传到公开仓库或 Issue；程序里的授权登记不能代替参与者实际知情同意。

# 课堂签到 · Classroom Face Attendance

一个用 Python 和 OpenCV 编写的 Windows 桌面项目，尝试把**学生名单 → 人脸签到 → 考勤核对 → Excel 导出**串起来。程序在本机运行，数据保存在本地。

> **当前状态：开发与验证阶段，适合学习、演示和功能体验，暂不建议直接用于正式课堂考勤。**
>
> 维护者本地的数据仍在清洗整理，尚未公开。仓库不附带学生名单、人脸样本、训练好的识别模型或考勤数据库，下载后需要自行配置。
>
> 识别效果和长期稳定性尚未经过充分的真实课堂验证；已有功能和自动化测试不代表已经达到实际部署条件。

## 可以体验什么

- **教师管理**：添加学生、采集人脸、训练模型、创建课次。
- **学生签到**：老师开启课次后，学生逐人面对摄像头签到。
- **考勤整理**：查看记录、人工更正、导出 Excel，并备份本地数据。

技术栈：Python 3.11 · OpenCV · Tkinter · SQLite。不了解这些技术也可以按下面的步骤尝试运行。

## 怎么运行

准备一台 **Windows 10 / 11** 电脑，安装 **Python 3.11**。体验刷脸功能还需要摄像头；安装依赖需要联网，程序运行不依赖云服务。

**1. 下载源码**

在本仓库页面点击 **Code → Download ZIP**，解压。打开能看到 `GUI.py` 和 `requirements.txt` 的文件夹，在这里打开 PowerShell（终端）。

**2. 安装依赖并启动**

依次执行下面三行命令；上一行成功后再执行下一行：

```powershell
py -3.11 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
./.venv/Scripts/python.exe GUI.py
```

如果提示找不到 `py`，先用 `python --version` 确认是 Python 3.11，再把第一行的 `py -3.11` 换成 `python`。以后启动只需执行最后一行。

**3. 先用测试资料熟悉界面**

进入“教师管理”，按界面提示设置自己的管理密码；项目没有默认密码。先添加虚构的学生信息，浏览名单和课次管理，暂时不用导入真实班级资料。

要体验刷脸，需另行准备本人或明确同意参与测试者的样本：**采集样本 → 更新识别模型 → 创建并开启课次 → 进入“学生签到”**。没有样本和模型时，无法直接刷脸签到。

## 使用前需要知道

- **没有可靠的活体检测**：不能承诺识别照片、视频代刷，识别结果需要人工核对。
- **可能认错或认不出**：光线、角度、遮挡和摄像头都会影响效果，目前没有可用于真实课堂承诺的准确率数据。
- **面向单机使用**：同一时刻一个签到课次，不支持多教室联网管理；Linux、macOS 和其他 Python 版本未验证。
- **请保护测试资料**：人脸、名单、数据库、模型和备份都不要上传到公开仓库或 Issue。数据清洗完成也不意味着可以公开真实人脸或学生信息。
